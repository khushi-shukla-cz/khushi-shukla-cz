## 💻 Featured Projects

### 🩺 OncoPilot — AI-Powered Breast Cancer Clinical Decision Support System

An intelligent clinical decision support platform designed to streamline breast cancer report analysis and assist clinicians with structured, evidence-based insights.

- Automated extraction of clinical biomarkers from medical documents.
- Processes ER, PR, HER2, Ki-67 and TNM staging information.
- Rule-based clinical reasoning with guideline-informed recommendations.
- Handles missing, equivocal and negated clinical findings.
- Designed with clinician review and decision control.

**Tech:** Next.js • FastAPI • Python • PostgreSQL • NLP • OCR • Docker

### 🔗 TrustChain — Blockchain-Based Transparent Charity Platform

A decentralized charity donation and fund-tracking platform built around smart contracts and transparent fund management.

- Smart-contract-based donation management.
- Transparent campaign and donation tracking.
- Milestone-based fund release and escrow workflows.
- NGO dashboards, donor dashboards and audit trails.
- Blockchain-powered accountability.

**Tech:** Solidity • Ethereum • React • JavaScript • Web3

[View Repository](https://github.com/khushi-shukla-cz/Trustchain)

### 📊 Real-Time UPI Fraud Detection & Risk Monitoring

A data-driven fraud detection system designed to identify suspicious UPI transactions and monitor transaction risk.

- Transaction preprocessing and feature engineering.
- Machine learning-based fraud classification.
- Random Forest model for fraud risk prediction.
- Risk monitoring and analytical dashboards.
- Big data processing using Hadoop ecosystem technologies.

**Tech:** Python • Machine Learning • Random Forest • HDFS • MapReduce • Streamlit
